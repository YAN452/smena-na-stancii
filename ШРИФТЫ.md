# Шрифты и лицензии

Курс использует четыре свободных шрифта. Все допускают распространение,
два требуют указания автора — оно приведено ниже и в подвале курса.

## В работе

**Greengoth** — заголовки курса.
Автор: **Dimitri Antonov / Blue Curve Designstudio**.
Лицензия: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
Изменения: шрифт не модифицировался, подключён как есть в формате TTF.

**Golos Text** — основной текст. Лицензия SIL Open Font License 1.1, © Paratype.

**JetBrains Mono** — время, подписи, цифры. Лицензия SIL Open Font License 1.1, © JetBrains.

**Oswald** — запасной заголовочный, если Greengoth не загрузился. SIL OFL 1.1.

## Лежат в наборе, но в вёрстке не используются

**Mephisto** — акцидентная антиква.
Автор: **rdvdesign** ([behance.net/rdvdesign](https://www.behance.net/rdvdesign)).
Лицензия: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

**Tovar** — сверхжирный юникейс-гротеск.
Автор: **Илья Колобов** ([behance.net/komatype](https://www.behance.net/komatype)).
Свободен для коммерческого использования.

**Bubble Sans** — округлый гротеск.
[Проект на GitHub](https://github.com/abayemes/bubblesans), лицензия SIL Open Font License 1.1,
© 2025 The Bubble Sans Project Authors.

## Как переключить заголовочный шрифт

В `styles.css` в блоке `:root`:

```css
--display:"Greengoth","Oswald","Arial Narrow",sans-serif;
```

Допустимые значения: `Greengoth`, `Tovar`, `Mephisto`, `BubbleSans`, `Oswald`.
Файлы уже лежат в `vendor/fonts/`, объявления — в `vendor/fonts/brand.css`.
Пересобирать курс после смены не нужно, только обновить страницу.

## Откуда файлы

Исходные архивы — в `бренд/`, распакованные — в `бренд/распаковано/`
(в репозиторий не попадают, см. `.gitignore`). В сборку идут только
скопированные в `vendor/fonts/` начертания.
